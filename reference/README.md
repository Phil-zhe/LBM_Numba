# Ghia Re=100 reference data

The CSV files transcribe the centerline velocity tables from U. Ghia,
K. N. Ghia, and C. T. Shin, “High-Re solutions for incompressible flow using
the Navier-Stokes equations and a multigrid method,” *Journal of Computational
Physics* 48 (1982), 387–411. `u` is the horizontal velocity on the vertical
centerline and `v` the vertical velocity on the horizontal centerline; both are
normalized by lid velocity. Values were manually transcribed from the tables
reproduced in the project prompt and checked row-by-row.
